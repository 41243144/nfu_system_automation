# 虎尾科大自動登入工具

## 簡介
此工具用於自動登入虎尾科技大學和雲林科技大學的校務系統，提供簡單易用的 GUI 界面，並整合 ONNX 模型進行驗證。

## 下載
您可以從以下位置下載此工具：

- [GitHub Releases](https://github.com/your-repo-name/releases)

## 功能
- 自動登入校務系統。
- 支援多校系統（虎尾科大、雲林科大）。
- 提供 GUI 界面，方便操作。
- 支援自定義設定檔。

## 使用方式
1. 啟動程式後，輸入帳號和密碼。
2. 選擇目標校務系統。
